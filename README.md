# The Gospel of the Unseen — Website v1

A responsive, static website concept for **The Gospel of the Unseen**, an independent sacred arts journal centred on Scripture, Christian contemplation, and original visual art.

## Included
- Responsive landing page with original visual identity
- Scripture reader with passage navigation and copy action
- Editorial contemplation cards with accessible article dialogs
- Four thematic reading pathways
- Purpose and editorial-principles section
- Newsletter signup UI with a transparent front-end-only notice
- Mobile navigation, reduced-motion support, keyboard focus styling, and SEO/social metadata
- WebP-optimized artwork derived from the images created for this project

## Run locally
Open `index.html` in a browser. For a local server, run one of:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` from this folder.

## Deploy
This is a static site and can be deployed to GitHub Pages, Netlify, Cloudflare Pages, or any static web host. Upload the contents of this folder while preserving the `assets/` directory.

## Before public launch
1. Connect the newsletter form to a mailing-list provider or a secure backend. The current form deliberately does not save or transmit email addresses.
2. Replace the generic X/Twitter link with the verified account URL.
3. Add final About/editorial details, contact information, privacy policy, and accessibility/legal notices appropriate to the project.
4. Test page metadata, image crop, mobile layout, and actual deployment URL.
5. Review all Scripture quotations and references in their full context before publishing new essays.

## Project principles
Scripture first. Art serves contemplation; it does not replace biblical text. Clearly distinguish the biblical passage from original reflection or artistic interpretation.
